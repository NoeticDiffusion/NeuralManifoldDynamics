```powershell

  "K:\ExternalReceivedDatasets\openneuro\received\ds006848"
```

Result: `install(ok)` — 30 subject directories cloned (metadata only; .eeg files are annex

Noted: `datalad install` (old API) is deprecated; `datalad clone` is correct in datalad ≥1.0.

### 2. Event structure inspection

Inspected `sub-001_task-verbalwm_events.tsv` and `sub-001_task-rest_events.tsv` to confirm
actual `trial_type` labels:

**verbalwm events:**
- `Baseline_2s` — 2-s pre-encoding baseline
- `Encoding_DigitValue_0` … `9`, `Encoding_Set_Simultaneous` — digit encoding
- `Retention_Simultaneous`, `Retention_Fast`, `Retention_FastDelay`, `Retention_Slow` — 6-s retention (condition label)
- `Digits_Retrieval` — recall phase (~18 s)
- `Rest`, `Experiment_End`, `Boundary`

**rest events:**
- `Eyes_Closed`, `Eyes_Opened`, `Start_Cartoon`, `End_Cartoon`, `Boundary`

Key insight: The `Retention_*` event is the cleanest condition identifier. The encoding mode
determines which `Retention_*` marker fires.

### 3. Data download

Started `datalad get` for all `*.eeg`, `*.vhdr`, `*.vmrk` files (30 subjects × 2 tasks × 3
files ≈ 180 files, several GB). Running in background on K: drive.

### 4. Config written

`mndm/config/config_ingest_ds006848.yaml` created with:

- `source.format: BIDS` (BrainVision)
- `paths.dataset_received_dirs.ds006848: K:/ExternalReceivedDatasets/openneuro/received/ds006848`
- `features.ecg.peak_detector: neurokit2` (inheriting ds003838 T-wave fix)
- `within_run_labels` codebook with confirmed event names → integer codes
- `event_locked` anchored on `Retention_*` events (6-s retention window, with ±2/6/12-s bins)
- `block_native` using `Retention_*` and rest-state events as block markers
  (4-s sliding windows, 2-s step)
- `block_jacobians: enabled: false` (as in ds003838; avoids massive output)

## Known limitations / open questions

1. **Block duration mismatch** — each `Retention_*` block is only 6 s; with 4-s windows and 2-s
   step there is only 1–2 windows per trial. For robust block_native analysis, consider
   aggregating same-condition trials or using the full trial epoch (baseline→retrieval, ~28 s).
2. **8 subjects lack rest data** (sub-002/003/004/005/006/008/009/011); rest analyses will be N≤22.
3. **ECG/PPG channels** — these are co-recorded in the BrainVision EEG file. The MNDM indexer
   must correctly split them out during the `features` stage. Verify after first run.
4. **within_run_labels event_map** — currently maps individual Encoding_DigitValue_X events to
   a generic `encoding` state. Finer-grained analysis (e.g., per-digit epoch) possible if needed.
5. **Behavioral data** — `_beh.tsv` has trial-level accuracy and partial scores; could be used to
   stratify by performance (correct vs incorrect trials) in a future analysis.
