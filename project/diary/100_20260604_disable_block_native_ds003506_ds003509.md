# 100 20260604 disable_block_native_ds003506_ds003509

## Context

User requested returning `ds003506` and `ds003509` to normal (non-block-native)
mode. Rationale: trial-level events (e.g., left/right button choices) are less
important than session-level ON/OFF medication contrasts from `participants.tsv`,
so block-native segmentation should be removed for these two Parkinson datasets.

## Config changes

Updated:

- `mndm/config/config_ingest_ds003506.yaml`
- `mndm/config/config_ingest_ds003509.yaml`

For both datasets:

- `block_native.datasets.<dataset>.enabled: true -> false`

The block-native section remains in file for future reuse, but is fully disabled.
