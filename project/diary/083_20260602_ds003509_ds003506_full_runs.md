# ds003509 + ds003506 cleanup, staging, smoke, and full runs

## Question

Can the OpenNeuro Parkinson/control EEG cohorts `ds003509` and `ds003506` be brought to a clean trigger-enriched staging state, smoke-tested, and then run through full `features` + `summarize` without the stray `raw_nan_onset_sec` surface?

## Work completed

1. Updated `project/smoke_tests/stage_ds003509_trigger_enriched.py` so staged `events.tsv` files drop the `STATUS` boundary row before export. This removes the empty/NaN event subtype pathway that previously surfaced as `raw_nan_onset_sec`.
2. Rebuilt `M:/datasets/received/openneuro/ds003509_trigger_enriched`.
3. Re-ran the `ds003509` smoke path for `sub-002` and confirmed the new summary tree no longer contains `raw_nan_onset_sec`.
4. Added `project/smoke_tests/stage_ds003506_trigger_enriched.py`, which:
   - hardlinks/copies the source tree into `M:/datasets/received/openneuro/ds003506_trigger_enriched`,
   - rewrites only the BIDS event sidecars,
   - derives compact `choose_*` / `match_*` instruction, stimulus, response, and feedback labels,
   - propagates `trial_mode`, `response_hand`, `feedback_outcome`, and trial indices.
5. Updated `mndm/config/config_ingest_ds003506.yaml` to use the trigger-enriched staged root and `event_subtype_role` as the provenance event surface.
6. Ran smoke and full `features` + `summarize` for both datasets.

## Notes / limitations

- For both datasets, `mnps_projection.export_contracts.cohort_anchored=true` was requested in config but skipped at runtime because no external cohort anchor was active.
- Several recordings emitted the existing `CRITICAL WARNING: 9D MNPS falsified for this session. Matrix is effectively 3-dimensional.` log line during summarize. This did not stop the runs and appears to be the current expected warning surface for low-rank sessions rather than a new regression introduced here.
- The MNE runtime still warns that the raw `.set` files contain EEGLAB `boundary` events. That warning is about the raw EEG container metadata; the staged BIDS event sidecars no longer export the `STATUS` row into the MNDM event provenance surface for `ds003509`.
