# Session Diary 080 - ds003509 and ds003506 config bootstrap

Date: 2026-06-02

## Goal

Bootstrap MNDM EEG ingest overlays for OpenNeuro Parkinson/control datasets:

- `ds003509` - Simon conflict task
- `ds003506` - reinforcement learning task

## Dataset facts verified from the downloaded BIDS trees

Common structure verified for both datasets:

- `participants.tsv` contains:
  - `participant_id`
  - `Group`
  - `sess1_Med`
  - `sess2_Med`
  - `sex`
  - `age`
- Parkinson participants have two sessions with ON/OFF medication labels
- controls only have one real session and carry `n/a` / `no s2`
- EEG channel lists include:
  - standard 64-channel scalp montage
  - `VEOG`
  - accelerometer channels `X`, `Y`, `Z`

Task-specific event surface verified:

- `ds003509` events.tsv exposes many point-like trigger labels in `trial_type`
  (training/test stimuli, responses, feedback)
- `ds003506` events.tsv exposes coarse instruction / imperative stimulus /
  button-choice / feedback markers in `trial_type`
- neither dataset currently exposes a clean continuous block/stage contract that
  should replace the canonical stage axis for 8 s overlapping windows

## Main config choices

Shared choices for both overlays:

- point `received_dir` to `M:/datasets/received/openneuro`
- point `processed_dir` to `M:/datasets/processed/openneuro`
- keep explicit `dataset_received_dirs` per dataset
- enable `event_mapping` so raw BIDS events can be surfaced as auditable
  window-aligned binary labels
- keep `prefer_events_stage_in_summary: false` so raw point events are not
  misused as a single canonical stage per MNPS window
- type accelerometer channels `X|Y|Z` as `misc`
- use `eog_reg` artifact handling because `VEOG` is present
- enable Parkinson-facing conventional EEG comparator packs:
  - `tier1`
  - `complexity`
- enable regional MNPS, stratified outputs, and 9D block Jacobians
- extract `group` from `Group`
- extract session-aware medication `condition` from:
  - `sess1_Med` for `ses-01`
  - `sess2_Med` for `ses-02`
- normalize:
  - `PD -> Parkinson`
  - `CTL -> Control`
  - `ON -> ON`
  - `OFF -> OFF`
  - `n/a` / `no s2` -> `not_applicable`

Task normalization:

- `ds003509`: `SimonConflict -> simon_conflict`
- `ds003506`: `ReinforcementLearning -> reinforcement_learning`
