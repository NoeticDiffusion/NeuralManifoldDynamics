# 102 20260605 dual_anchor_rerun_ds003506_ds003509

## Context

Latest full runs for `ds003506` and `ds003509` reported only subject-anchored
coordinate layers, while cohort-anchored layers were requested in config.

User requested:

1. verify current data/manifests,
2. debug if dual-anchor emission failed,
3. rerun.

## Verification of failing runs

Checked latest pre-fix run manifests:

- `ds003506`: `neuralmanifolddynamics_ds003506_20260604_181839`
- `ds003509`: `neuralmanifolddynamics_ds003509_20260604_185413`

Observed for both:

- `requested_contracts = ["subject_anchored", "cohort_anchored"]`
- `realized_contracts = ["subject_anchored"]`
- `h5_with_coords_3d_cohort_anchored = 0`
- `h5_with_coords_9d_cohort_anchored = 0`

Spot checks in representative H5 files confirmed cohort layers were absent.

## Root cause

No active feature-anchor source was configured for these datasets.

`cohort_anchored` was requested but could not be emitted without a frozen anchor
artifact (external anchor or one-shot anchor fit).

## Fix

Updated both dataset configs:

- `mndm/config/config_ingest_ds003506.yaml`
- `mndm/config/config_ingest_ds003509.yaml`

Added under `mnps_projection`:

- `anchor_auto_fit.enabled: true`
- stable dataset-specific `anchor_id`
- `anchor_source`
- `scale_method: "iqr"`
- `min_subjects: 3`

## Reruns (features + summarize)

python -m mndm.cli all --dataset ds003506 --config mndm/config/config_ingest_ds003506.yaml --n-jobs 1
