# Historical article material

The files in this directory are preserved records from earlier or draft
versions of the NeuralManifoldDynamics article. They are not part of the
current multimodal methods article or its active supplementary package.

The archived S2, S3, and S4 Typst sources and PDFs were formerly stored beside
the current sources. S2–S4 describe earlier analyses and should not be used as
validation for the current EEG definition or its separate MEG/LFP pilots. The
S3 source explicitly records an unresolved count difference: its full-session
total is 3,433 epochs per probe, while the listed state counts sum to 1,837;
the archived record does not explain the remaining 1,596 epochs. Its PDF is
preserved as a prior rendering and does not include that clarification. S4's
source distinguishes human clinical samples from the ancillary rodent state
and stimulation audits; its archived PDF predates that edit.

`figures/version_timeline_v3_4_draft.svg` is also archived because it is not
referenced by the active article and describes v3.4 as having no Jacobian,
which is ambiguous with the separate additive Jacobian export.

Archived PDFs are retained unchanged. The active Typst sources in the parent
directory are the current text sources; the existing PDFs were not regenerated
for this revision.
